## 🇬🇧🇺🇸 English

This resource pack provides an unofficial Russian translation for the [The Harpy Express: Extended](https://modrinth.com/modpack/the-harpy-express-extended) modpack.

#### Download options

- Download the latest release from the [GitHub Releases](https://github.com/Agent19872/thee-rus/releases/tag/latest) page.
- Download a stable release from the Modrinth [Versions](https://modrinth.com/resourcepack/thee-rus/versions) page.

#### Installation

1. Download the latest or stable release.
2. Open the directory containing the resources and mods for The Harpy Express: Extended modpack.
3. Open the `resourcepacks` folder.
4. Copy the downloaded resource pack into this folder.
5. Launch Minecraft, select `Русский язык`, and enable the resource pack.

## 🇷🇺 Русский

Этот ресурспак содержит неофициальный перевод сборки [The Harpy Express: Extended](https://modrinth.com/modpack/the-harpy-express-extended) на русский язык.

#### Варианты загрузки

- Последняя версия доступна на странице [релизов GitHub](https://github.com/Agent19872/thee-rus/releases/tag/latest).
- Стабильную версию можно скачать на странице [Versions](https://modrinth.com/resourcepack/thee-rus/versions) в Modrinth.

#### Установка

1. Скачайте последнюю или стабильную версию.
2. Откройте директорию, в которой находятся ресурсы и моды сборки The Harpy Express: Extended.
3. Откройте папку `resourcepacks`.
4. Скопируйте скачанный ресурспак в эту папку.
5. Запустите Minecraft, выберите `Русский язык` и включите ресурспак.
